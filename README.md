# SmartTour Big Data

Proyecto para analizar datos turísticos mediante tecnologías Big Data.

## Tecnologías

- Python
- Docker
- JupyterLab
- Pandas

## Instalación

docker compose up

## Objetivo

Analizar demanda turística y crear cuadros de mando.

## Estructura

datasets:
Datos utilizados en el proyecto.

scripts:
Programas Python.

notebooks:
Análisis realizados.

docs:
Documentación.
